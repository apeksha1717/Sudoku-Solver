Sudoku Solver in Java

📌 Project Description

Sudoku Solver is a Java-based application that automatically solves a 9×9 Sudoku puzzle using the Backtracking Algorithm and Recursion. It checks the Sudoku rules and finds a valid solution for the given puzzle.

✨ Features

- Solves a 9×9 Sudoku puzzle automatically.
- Checks row, column, and 3×3 box constraints.
- Uses recursion to explore possible solutions.
- Uses backtracking when a number leads to an invalid solution.
- Displays the original and solved Sudoku boards.

🛠️ Technologies Used

- Java
- Two-Dimensional Arrays
- Recursion
- Backtracking Algorithm

⚙️ How to Run

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project in VS Code or IntelliJ IDEA.
4. Open "SudokuSolver.java".
5. Compile and run the program.

Run using the terminal

javac SudokuSolver.java
java SudokuSolver
